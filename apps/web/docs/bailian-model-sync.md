## 日常操作

1. 后台 → 平台模型 → 百炼模型目录，选择连接并搜索模型。
2. 可适配且规格完整的模型点击“添加并开放”；价格策略默认为跟随百炼目录价。
3. 已有模型在“配置与同步详情”中修改显示名称、连接和收费策略。
4. 保存高级手动配置会退出自动同步，手动值不会随后被同步覆盖。

## 明确的边界

- 百炼目录不是账户调用授权证明。选择模型不等于 API Key 已有相应调用权限。
- 同步的是公开目录价格，不是优惠、赠送余额或实际账单。Batch、显式缓存和隐式缓存不能混用。
- 峰谷价格可能只有 `peak/offpeak` 标签，没有时区/时间段。系统不会猜测：连接设置须先确认规则，才允许跟随峰谷收费；不影响同步能力及价格参考，也不影响原固定收费。
- 当前自动推理适配覆盖百炼 DeepSeek V4 的已验证 ID、Qwen3 Max、Qwen Plus/Flash 及 Qwen3.5 Plus/Flash；未知协议显示“待适配”，允许高级手动接入，不套用其他模型档位。
- 每次请求开始时固定当次费率，跨峰谷边界或同步更新不追改已经开始的请求。
- Web 会话费用仍是估算；平台后台结算为准。正在运行的会话不会中途切换描述，下一次模型请求前更新。
- 自动更新不改模型 ID、不自动删除下线模型。目录中的下线公告显示在后台。
- 后台当前是单 Uvicorn 进程；多进程/多副本部署前须将写入锁升级为跨进程锁或数据库事务。

## 文件与部署

服务器项目：`/home/PE_Workbench_backend`，容器 `pe-workbench-backend`。
有效配置：`/var/lib/pe-workbench/model-config/model_gateway.toml`。
连接及状态：同目录 `bailian-sync.json`（仅环境变量引用，不含密钥）。
同步备份：同目录 `sync-backups/`，按旧配置哈希保存；未自动删除历史备份。
本次部署前源码/配置备份：`/home/PE_Workbench_backend/backups/bailian-sync-20260914/`。
部署前镜像：`pe_workbench_backend-backend:before-bailian-sync-20260914`。

本地改动仅在 WSL `PE-Workbench-pi-web`；Pi 核心无需修改。
重新启动 Web 的 `npm run dev` 后刷新页面，以避免旧的热更新进程保留缓存。
