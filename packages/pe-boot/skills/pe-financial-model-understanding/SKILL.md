# 📝 理解财务模型

交付“这位分析师怎么算的”。取证遵循 [reader](../pe-financial-model-reader/SKILL.md)；输入角色、说明交接及验收A统一使用 [模型说明与理解验收](../valuation-model-review/references/model-understanding.md)。涉及数值复算或敏感性时使用 [估值公共规则](../valuation-model-review/references/valuation-methods.md)。两份公共参考随能力加载；直接使用已注入正文，按问题取相关规则，不重新扫描已覆盖范围。

## 按请求确定范围

- 整体模型分析或“先解构再继续”：交付公共参考中的结构概览、四部分模型说明、关键路径与适用的U1—U6结果，再继续用户已请求的模块。
- 单项数值、公式或敏感性问题：只解释并验收相关链，默认简短结论和最短可核验路径；仅用户要求追到底或详细审阅时展开，不抄工具日志或所有读到的单元格。
- 截图、公式摘录或无法打开的工作簿：仅陈述可验证范围，不声称完成整本解构。受限后台按可用工具交付说明及缺口，不声称已复算或保存文件。

## 📝 说明与交接

按公共参考交接说明、输入角色、路径证据、A状态、范围和未知项；核对文件版本及证据可访问性，只补新问题或变更路径。模型怎么算、记载的选值理由与外部证据是否支持分开，不替分析师编动机。

普通模型说明不强制报告工具、框架状态或图表。引用沿用reader返回的逐项证据；附件没有项目引用时用文件名及sheet!cell。形成投资判断时接续 [投资研究](../pe-investment-research/SKILL.md)，不自动改参数、更新历史或输出买卖建议。
