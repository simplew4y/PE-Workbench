# 理解财务模型

交付“分析师怎么算的”。取证使用 [reader](../pe-financial-model-reader/SKILL.md)，复用已有读取结果；单纯模型理解不要求整体估值报告工具。

## 范围与共同规则

输入角色、四部分模型说明、验收A和接续规则统一使用 [模型说明与理解验收](../valuation-model-review/references/model-understanding.md)。已加载时直接复用；单项问题只取相关规则，不扩大为全模型验收。

整体模型分析或审核先交付结构概览、四部分说明与A的实际结果，再继续用户已请求的模块；只问模型说明则到此结束。截图或摘录仅支持可见范围，不能声称核对了原工作簿。

同文件、同版本、同范围的可复核成果直接接续，新增问题或版本变化定向补查。交接保留说明、输入角色、路径证据、范围、A状态与未知项，不只传结论摘要；普通聊天不强制创建框架状态。

## 受限入口也必须保留的判断

后台仅有读取/提交工具、无法读取上述参考时，在允许的输出中解释当前链及缺口，不调用不可用的文件或复算工具，也不声称完成完整验收：

- 从所问输出沿真实公式追到有业务含义的独立输入或明确断点；按依赖方向判断角色，不按增长率/毛利率等名称判断。公式内常数也可能是判断，派生结果供下游引用不算新的独立判断；跨期沿用须查原引用。
- 分开模型角色、实际/预测状态和硬填/公式/外部引用方式，以期间、公式及注释举证，颜色只能辅助。保持模型当时基线，今天已公布的实际不覆盖旧预测；不强套量价或毛利率模型。
- 保留范围内的冲突输出、价格基准和未解析依赖；不能因隐藏、无颜色或搜索未命中而排除。分页与追踪完整性按reader核查，局部复算不是全表重算。
- 区分公式可证的“怎么算”、资料记载的“为何这样设”与需要外证的“是否可信”。关键输入不等于最敏感；未经可比扰动不排名，EPS等派生结果替换不冒称上游输入测试。

## 交付

默认简短结论、关键输入及最短可复核路径，说明期间、单位、结果与限制；详细链按请求展开，不抄工具日志。沿用reader逐项引用，附件没有项目引用时用文件名与sheet!cell。正文讲机制，准确公式和坐标放证据，不编分析师动机。

需要投资判断时接续 [投资研究](../pe-investment-research/SKILL.md)，保留模型证据与缺口，不自动改参数、更新历史值或生成买卖建议。
