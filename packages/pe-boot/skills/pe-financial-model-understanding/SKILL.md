# 理解财务模型

交付“这位分析师怎么算的”。取证遵循 [reader](../pe-financial-model-reader/SKILL.md)；输入角色、依赖方向、解释边界及验收A统一遵循 [模型说明与理解验收](../valuation-model-review/references/model-understanding.md)。该公共参考随能力加载，已有内容直接使用，不再扫描同版本同范围的表。

## 按请求确定范围

- 整体模型分析或“先解构再继续”：交付公共参考中的结构概览、四部分模型说明、关键路径与适用的U1—U6结果，再继续用户已请求的模块。
- 单项数值、公式或敏感性问题：只解释并验收相关链，默认简短结论和最短可核验路径；仅用户要求追到底或详细审阅时展开，不抄工具日志或所有读到的单元格。
- 截图、公式摘录或无法打开的工作簿：仅陈述可验证范围，不声称完成整本解构。受限后台按可用工具交付说明及缺口，不声称已复算或保存文件。

## 说明与交接

按公共参考保留结果、真实输入角色、路径证据及影响当前结论的未知项。模型怎么算、模型记录的选值理由、外部证据是否支持分别陈述；没有理由就提出具体核验问题，不替分析师编动机。

普通模型说明不强制报告工具、框架状态或图表。引用沿用reader返回的逐项证据；附件没有项目引用时用文件名及sheet!cell。后续研究复用同一版本的说明、证据和验收范围，按公共参考的交接规则补查差异。形成投资判断时转入 [投资研究](../pe-investment-research/SKILL.md)，不自动改参数、更新历史或输出买卖建议。
