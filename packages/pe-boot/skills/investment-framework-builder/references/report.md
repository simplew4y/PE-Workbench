# 最终报告与图表

## 两部分，不混成一次验收

有原工作簿时，标题为公司名称及具体研究问题，注明资料版本、信息截止、单位及预测起点。先呈现**第一部分：分析师的模型说明**，再呈现**第二部分：投资研究**。保留独立 `模型说明.md`，正文复用同一内容，避免写出两套冲突的机制。无工作簿时说明第一部分不适用，不能声称已经还原Excel。

第一部分直接复用 [模型说明与理解验收](../../valuation-model-review/references/model-understanding.md) 规定的四部分说明、输入角色、路径证据、验收A及缺口，不另写一份机制解释。先按该参考核对文件身份、版本和覆盖范围；新增版本或问题只补查相关差异。不得用后续实际、市场预期或可信度讨论打断原模型说明。只要求模型说明时交付至此，不追加投资章节或强制画图。

第二部分保留已有投资研究内容，去除第一部分已解释的重复计算：

1. **当前投资判断**：最后生成、置于本部分开头。更有支持的逻辑、回报条件、最大不确定性及实质变化；不抢在模型说明之前。
2. **经营条件与兑现**：公司商业机制、关键KPI、原假设需要的现实条件、后续实际和重要差异。会计增减桥可辅助，不充当预测输入链。
3. **候选逻辑与正反证据**：支持、反证、替代解释和缺口；“怎么算”“模型记录的理由”“研究者判断是否可信”分别标识。
4. **市场预期、估值与回报**：预测差异、保守价值与下行、敏感性、价值实现条件及时间。
5. **改判条件与关键变量追踪**：关联重点变量及逻辑，说明何时、依据什么重新判断。
6. **证据、未知问题与版本变化**：模型来源、外部来源、决定性缺口、实质变更及验收B状态。列研究对象、用户期限、偏好和信息截止；未知不猜测。

可按内容合并第二部分重复表格，不加更多投资框架章节。模型未给理由只说明缺依据，不替分析师编动机；证据不足写“还不能判断”。偏好决定深度，不改变事实。正文给计算与判断依据，不呈现agent操作日志。

完整研究的图表范围、模块责任和质量统一执行 [图表公共规则](../../valuation-model-review/references/chart-quality.md)。Builder将适用的趋势、敏感性、追踪三张主图分别置于第二部分的“经营条件与兑现”“市场预期、估值与回报”“改判条件与关键变量追踪”，保留生成附件并简述含义；两阶段验收不增加图数，缺项在gaps说明。

## 交付核对

分别展示验收A、B及范围。A检查真正输入→预测依赖→原输出的可核验性；B检查证据→经营条件→候选逻辑→估值→改判条件的成立程度。A通过不等于模型无误或B通过；A核心链未通过不能授予整份研究完整通过状态。按缺口定向补查，不以润色、章节齐全或结构校验代替两次验收。
