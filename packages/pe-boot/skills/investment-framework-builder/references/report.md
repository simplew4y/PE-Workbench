# 最终报告与图表

## 两部分，不混成一次验收

有原工作簿时，标题为公司名称及具体研究问题，注明资料版本、信息截止、单位及预测起点。先呈现**第一部分：分析师的模型说明**，再呈现**第二部分：投资研究**。保留独立 `模型说明.md`，正文复用同一内容，避免写出两套冲突的机制。无工作簿时说明第一部分不适用，不能声称已经还原Excel。

第一部分按 [模型说明与理解验收](../../valuation-model-review/references/model-understanding.md) 的四部分：

1. **收入怎么预测**：拆分、历史/预测基数、真正增长与汇率输入、跨期沿用、年度汇总/增长率倒算。
2. **成本与利润怎么预测**：收入至毛利、费用、营业利润、税项、归母利润与EPS的依赖；直接设定、沿用和计算分开。
3. **现金流与估值怎么形成**：必要投入、现金流关系、主预测接点与独立估值参数、价值桥、股价口径。
4. **模型没有告诉我们什么**：未记录的理由、未建模的驱动、未解析依赖、已证实冲突。附验收A状态、代表路径范围和未完成项。

每部分是白话机制、少数关键输入和可核验路径；原公式及坐标进证据附录。不得用后续实际、市场预期或可信度讨论打断原模型说明。只要求模型说明时交付至此，不追加投资章节或强制画图。

保持上述大结构，在现有关键输入/公式表中增加“模型角色”标记，正文说明“先判断什么→怎么算→得到什么”。增长率与毛利率不能因名称就列为假设；同一指标是判断、计算结果还是上游结果的引用，由真实依赖决定。颜色、公式、批注与跨表引用用于举证，不作为单独的理解产出。

第二部分保留已有投资研究内容，去除第一部分已解释的重复计算：

1. **当前投资判断**：最后生成、置于本部分开头。更有支持的逻辑、回报条件、最大不确定性及实质变化；不抢在模型说明之前。
2. **经营条件与兑现**：公司商业机制、关键KPI、原假设需要的现实条件、后续实际和重要差异。会计增减桥可辅助，不充当预测输入链。
3. **候选逻辑与正反证据**：支持、反证、替代解释和缺口；“怎么算”“模型记录的理由”“研究者判断是否可信”分别标识。
4. **市场预期、估值与回报**：预测差异、保守价值与下行、敏感性、价值实现条件及时间。
5. **改判条件与关键变量追踪**：关联重点变量及逻辑，说明何时、依据什么重新判断。
6. **证据、未知问题与版本变化**：模型来源、外部来源、决定性缺口、实质变更及验收B状态。列研究对象、用户期限、偏好和信息截止；未知不猜测。

可按内容合并第二部分重复表格，不加更多投资框架章节。模型未给理由只说明缺依据，不替分析师编动机；证据不足写“还不能判断”。偏好决定深度，不改变事实。正文给计算与判断依据，不呈现agent操作日志。

## 三张主图

完整投资研究仍只保留三张主图，实际运行Python生成PNG，保留脚本和底层数据、嵌图并简短解释；两阶段验收不增加图的数量。

1. 第二部分“经营条件与兑现”：**历史与预测关键指标趋势图**，展示适用增长、利润率及投入或现金流指标，标出预测起点。
2. “市场预期、估值与回报”：**敏感性分析图**，用有依据的真正输入扰动；默认龙卷风，必要时热力图替代，不把所有图型各画一遍。EPS条件替换不能充作底层输入链测试。
3. “改判条件与关键变量追踪”：**关键变量追踪图**，最多三分栏，承接敏感性筛出的变量。保留原基线，后续实际、市场预测及条件反推分别标注。无后续实际则显示历史与原预测，注明待验证。

图与正文使用同一方法、年份、版本和可比口径。资料不足说明缺项，不凑图，不额外堆叠驱动图、估值区间图或时间线。中文字体、标签、裁切、引用路径均需检查。

## 交付核对

分别展示验收A、B及范围。A检查真正输入→预测依赖→原输出的可核验性；B检查证据→经营条件→候选逻辑→估值→改判条件的成立程度。A通过不等于模型无误或B通过；A核心链未通过不能授予整份研究完整通过状态。按缺口定向补查，不以润色、章节齐全或结构校验代替两次验收。
