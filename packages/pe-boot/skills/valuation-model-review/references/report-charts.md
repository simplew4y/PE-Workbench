# 报告图表共同规范

仅在任务需要图表时读取。模型说明和单项问答不强制画图；模型审核选取相关趋势/敏感性图，追踪图仅在用户要求跟踪或核对假设兑现时使用。完整投资研究保留适用的三张主图，不因两阶段验收增加图数。

| 主图 | 数据与模块责任 |
| --- | --- |
| 历史与预测关键指标趋势 | Business 提供适用的增长、利润率、投入或现金流指标及预测起点；保留原模型基线。 |
| 敏感性 | Valuation 提供符合 [复算与敏感性规则](valuation-methods.md) 的输入与结果。默认龙卷风，必要时用双变量热力图替代，不把所有图型各画一遍；价格条件对照明确标注，不能冒充经营输入测试。 |
| 关键变量追踪 | Monitoring 承接有依据的重点变量，最多三分栏。原预测、后续实际、市场预测与条件反推分别标明版本和日期；无后续实际时显示历史/原预测并注明待验证。 |

- 实际运行 Python/已安装绘图库生成 PNG，保留脚本、底层数据和来源，报告内嵌并解释。不能生成时说明限制，不以图占位符声称已完成；软件界面截图须来自实际界面。
- 图与正文采用同一方法、期间、版本和可比口径；季度与全年不直接比较，不以旧 DCF 图替代 P/E 分析。不同单位的局部响应不能据图排重要性。
- 检查数值、引用路径、预测分界、中文字体、标签与裁切。缺数据时说明缺项，不凑图，不额外堆叠驱动图、估值区间图或时间线。
