# 估值复现与敏感性公共规则

Review核验原模型，Explainer解释含义；独立定价和Expectations才按用户范围加入外部证据与研究情景。共用口径不等于执行同一份报告。输入角色与验收A遵循 [模型说明与理解验收](model-understanding.md)。

## 基准与价值桥

- 锁定文件身份、版本、估值日、预测期间、币种和单位，区分公式、保存缓存与本次独立复算。先复现适用的原输出并记录差额、单位及容差依据，再做扰动。仅局部复算不能称整本Excel重算；外链、宏、数据表或不支持函数阻断时，交付可验证部分和受影响缺口，不补假公式。
- 多种方法分别解释；只有原模型存在选择或加权关系才按其汇总，不自选主目标价。当前价、模型价格和目标价时点分别标明；模型缓存价不是实时行情。混用价格、年份或口径不能得到有效上涨空间。
- 依实际公式核对企业价值→股权价值→每股价值。核查现金、债务、租赁、少数股东权益及非经营资产的符号和口径，避免重复计入；区分基本/稀释、期末/加权股数。股数尺度不明时保留原值，不能凭数值大小换算。
- 现金流核对税、折旧、资本开支、营运资金、租赁及融资；含准备等项目的费用不能整行当纯折旧加回。现金或权益倒算只能说明算术一致，不能充当独立验证。缺少投入资本等数据时，不以空白公式零值证明资本回报。
- 相对估值说明目标年度、盈利调整口径及倍数依据。P/E按同口径EPS×倍数；EV/EBITDA等先桥接股权价值。比较历史或同业倍数需统一价格日期、期间和口径，有来源才称市场参考。
- DCF核对实际进入公式的现金流、折现率、折现时点及终值方法，不能拿辅助计算的资本成本替代实际参数。终值占比为“终值现值÷企业价值”；预测期价值和终值分别列示。原模型按原基准日复现；另估今天价值时滚动现金流时点并明确新情景，不能只替换日期。
- SOTP逐项保留分部指标、方法与参数，并核对总部费用和股权调整。方法是否适合公司需要证据，不能因为模型用了就认定合理。

## 两类敏感性，分别命名

### 原模型输入敏感性

先依据输入角色选择真正独立的上游假设，再从该输入重算实际受影响公式。增长率、毛利率可能是输入，也可能由收入或成本倒算；EPS、净利润、EBITDA、FCF若是计算结果，不能按名称列为独立经营输入。若原模型确实直接采用外部EPS预测，则注明外部来源及未覆盖的经营链，不伪称已验证其上游。

- 输入跨期沿用时按真实链接传播；相同值不证明有链接。只变动一个沿用期间或直接替换派生比率，属于切断依赖的新增反事实情景，必须单列，不能冒充原模型输入扰动。
- 记录原基准、扰动、单位、范围依据、固定条件、传播路径、复算范围和结果。有表内情景时先核对其方法和轴变量；表内EPS矩阵仍可能只是价格条件对照。
- 区间依历史、实际、经营约束或明确的局部步长决定，不机械统一±10%。百分比与百分点分开；不同单位的一单位变化不能直接排重要性。相关输入及其派生结果不重复当作独立变量；单变量影响不能直接相加，非线性和交互需按实际计算说明。
- 单项问题仅检查相关链；完整研究结合不确定性选择2—3个重点变量。图型和单双变量按问题决定，不默认强制“经营变量×估值变量”。没有可靠可比结果时只说明有证据的方向，不虚构排名。

### 价格条件对照

例如给定目标年度EPS和P/E的价格矩阵，回答“若盈利结果和倍数如此，价格是多少”。明确标为“价格条件对照”，列完整输入、原基准、固定条件及补充假设；非原表结果须注明。它不解释经营假设如何产生EPS，不能替代上游扰动或用来通过U5的输入传播检查。

- 固定EPS时价格变化为EPS×倍数变化；固定倍数时为倍数×EPS变化。这是线性关系，不能据此宣称非线性风险。简单EPS×P/E不要求无关的税或现金流输入。
- 若要从毛利率变动推导EPS，必须核查收入、费用金额、税、归属比例和股数等真实联动；固定收入和其他费用时，“收入×毛利率变化”才是税前利润变化，不能直接当归母利润。收入和EPS不天然同比变化。
- 净利润与EPS保持同期间、归属和股数口径。输入不全时说明不能量化的部分，不编精确估值变动。

## 研究情景与价格隐含条件

仅在独立定价或用户要求的投资研究范围内采用外部数据和研究假设。原模型、自身预测、市场共识及条件反推分开，保留来源、可得时间和价格时点；单一分析师不是市场共识。

情景与经营条件一致、范围有依据，不编概率或将压力情景称价值底线。反向估值声明固定条件及多解；现价除EPS再乘回同EPS是恒等式，不是独立合理价值证据。回报比较统一价格日期、币种及期限，区分价格/总/年化回报，回购现金与每股收益不重复计入，已派股息不计入新买入者回报。市场、同业或倍数合理性无来源时保留缺口。
