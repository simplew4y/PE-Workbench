# 估值复算与敏感性共同规则

供模型解释、模型审核、公司定价和投资研究按需使用。先读取已有模型说明和证据；输入角色遵循 [模型说明与理解验收](model-understanding.md)。本参考不要求启动完整报告或创建框架状态。

## 基准与价值桥

- 模型解释/审核保留原模型方法、日期和参数；研究新估值另列信息截止与假设，不把旧模型改日期称为当前价值。并列方法分别核验，没有选择或加权依据不合成目标价。
- 复现所问范围的基准，与保存缓存比较，记录原公式、输入、结果、差额、单位及容差依据。只读原表，使用导出副本或可用计算引擎；局部复算不称为全表重算。外链、宏、数据表或不支持函数阻断时标明范围，不补假公式。
- 金额、币种、期间、归母/调整后口径及股数尺度一致。基本、稀释、期末和加权股数不能互换；未确认尺度不得参与每股换算。价格比较注明股价日与预测/目标时点，模型缓存价不是实时行情。
- 企业价值到股权价值按实际方法核对现金、债务、租赁、少数股东权益、非经营资产及其他调整，避免重复计入。费用含准备等项目时不能整行作为纯折旧加回。

| 方法 | 核验重点 |
| --- | --- |
| P/E | 同期同口径 EPS × 倍数得到每股价格；若从净利润开始，先核对归属与股数。 |
| EV/EBITDA、P/S 等 | 先判定倍数分子是企业价值还是股权价值，再采用相应价值桥；不能见到销售或 EBITDA 倍数便直接当每股值。 |
| DCF | 预测现金流、投入/营运资金、实际进入公式的折现率、现金流时点和终值方法；终值占比＝终值现值÷企业价值。区分主预测引用与独立远期假设；辅助资本成本不等于公式实际使用值。新估值随估值日处理折现时点，不混旧基线。 |
| SOTP | 逐分部核对方法、期间、经营指标与参数，再处理总部费用及集团价值桥；防止分部与集团重复调整。 |

新研究选择方法须说明适用原因；原模型未记选择理由时，不以研究者解释冒充分析师动机。同业/历史比较统一价格时点、预测年度、调整口径、币种和单位，保留来源与样本限制。

## 两类敏感性，分别命名

### 原模型输入敏感性

回答“分析师的哪项独立假设改变，会怎样影响原输出”。先复现基准，再依据已核实的输入角色选变量，沿实际引用重算受影响链条。增长率或毛利率若由收入/成本倒算，应继续找上游输入；不能按指标名选变量。

- 跨期沿用按真实链接传播。只改某个被引用期间、切断链接或替换派生比率，属于新增反事实情景，需单列，不称为原模型输入扰动。
- 记录输入范围、步长、单位、固定条件、传播期间、输出与局部复算范围。扰动范围依据历史、经营约束或明确用户条件；缺合理范围可展示局部响应，不机械统一 ±10%。
- 相关输入和衍生结果不当作独立变量重复排名。不同单位的一单位变化不可直接比较重要性；有可比扰动与不确定性依据才排名。单变量结果不可直接相加；贡献归因须说明顺序与交互。
- 表内已有敏感性分析先核对其公式、轴、基准与范围，再按实际性质分类。线性/非线性结论来自计算结果与适用区间，不由图形或变量名决定。

### 价格条件对照

回答“给定盈利/现金流结果与估值参数，价格如何变化”。例如 EPS × P/E、EBITDA × EV/EBITDA 后接价值桥，或给定现金流下的 WACC 对照。汇总结果若由上游算出，这类替换不证明底层经营驱动已测试；若原模型确实直接设定该结果，可基于公式证据按独立输入处理。

- 标明“价格条件对照”及固定条件；补充计算同时标“假设情景，非原表结果”。它不能替代验收A所需的真正输入扰动，也不能据此给经营驱动排名。
- EPS × P/E 固定 EPS 时，价格变化＝EPS × 倍数变化；固定倍数时，价格变化＝倍数 × EPS 变化。这些是线性关系，不能据此宣称非线性风险。
- 当前价格除以 EPS 再乘回同一 EPS 是恒等式，不是独立合理价值证据。反向估值须说明固定条件、多解及条件性。

不默认要求“一个经营变量 × 一个估值变量”矩阵。按问题选择单变量或双变量；两轴必须写清经济角色和相互依赖。没有完整输入时保留可证实的方向与缺口，不造精确结果。

## 补充测算的口径

- 原表基准与新增情景分开，新增范围须有来源或标为自设条件；不能把自设倍数叫作同业均值或合理区间。简单 EPS × P/E 不要求无关税项或现金流输入。
- 百分比与百分点区分。只有收入及其他费用金额等固定时，“收入 × 毛利率变动”才是相应税前利润变化；再按模型税额、归属比例及同口径股数推到 EPS。收入与 EPS 不天然同比例，仅毛利率不变不足以支持等比例外推。
- DCF 情景使用实际折现公式和完整桥接输入；不能以无风险利率或未采用的辅助 WACC 替代。缺少必要输入不输出精确估值变动。
- 研究情景关联经营假设，区分原模型、研究预测、外部共识与条件反推。保守/基准/乐观相互一致；压力情景不是价值底线，不编概率。模型审核不因复算而自动加入市场观点或研究情景。
