# 图表质量与任务范围

只为当前任务生成有证据的图，不因为加载了公共参考就扩展报告或工具权限。

## 范围与责任

- 单项模型说明不强制图表，白话路径和简表足够时不画图。
- 模型审核按问题选择趋势或敏感性图；只有用户要求追踪或其确实支持本次审核时才加追踪图，不默认执行投资研究。
- 完整投资研究保留适用的三张主图：Business负责历史/预测趋势，Expectations负责敏感性，Monitoring负责关键变量追踪；Builder编排，Reviewer核验，不另做一套图。资料不足在gaps说明原因，不凑图。
- 趋势图标明原预测分界；敏感性图按 [估值公共规则](valuation-methods.md) 区分输入扰动和价格条件对照，完整研究的输入敏感性不能以EPS矩阵替代。优先适用的龙卷风图，必要时双变量热力图替代，不把所有图型画一遍。
- 追踪图最多三个分栏，承接已确认的重点变量；原基线、后续实际、市场预测和条件反推分别标注。没有后续实际时只画历史及原预测，注明待验证。倍数、折现率参考不能称经营实际。

## 生成与检查

有可用执行/文件工具时，以已安装Python绘图库生成PNG并实际检查，保留脚本与底层数据，报告内嵌图并简述含义。只提供读取/提交工具的后台不声称运行Python、生成文件或完成图表验收。

图和正文必须使用同一方法、文档版本、期间及单位，季度与全年不直接比较。保留原模型基线，不能用后续实际覆盖。注明来源与可回溯证据；不同单位局部响应标明不可直接排名。检查数值、中文字体、标签、图例、预测分界、裁切和引用路径，PE分析不能借旧DCF图替代。用户要软件截图时使用真实界面，生成图不能冒充Excel或Numbers截图。
