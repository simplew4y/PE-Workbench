# 模型说明与理解验收

用于回答“这位分析师怎么算出来的”。先独立交付模型说明，再讨论假设是否可信。完整投资报告复用同一份说明作为第一部分；单项问题只追相关链，不遍历整本工作簿。

## 四部分交付

每部分用**白话机制＋少数关键输入＋一条可核验路径＋结果/含义**。正文写工作表名称、年份与项目，不写 `表名!单元格` 或裸坐标乘法；准确坐标、原公式、缓存和复算放编号证据附录。至少让读者能沿路径找到真正的输入，而非只找到最后一层引用。

在现有关键输入/公式表中标明**模型角色**，并用一句话说明“分析师先设定什么，经过什么计算，得到什么”。保留报告已有大结构和原模型输出，不为角色区分新增章节或改写模型。

1. **收入怎么预测**：先识别实际预测起点与拆分维度，再说明历史/预测基数、真正输入及汇总/倒算方向。增长率可能是判断，也可能是收入算出后的结果；没有量价、门店或客户拆分就直说，不强制补成另一种模型。
2. **成本与利润怎么预测**：先查成本来自毛利率反推，还是原材料、人工、租金等明细汇总，或二者混用；再说明费用及利润的实际计算方向。哪些直接设定、跨期沿用或公式计算，串到营业利润、税前利润、税率、归母利润和EPS。会计增减桥可补充结果，不能代替这条预测依赖链。
3. **现金流与估值怎么形成**：利润到现金流的税、折旧、投入、营运资金等关系；估值真正引用主预测还是独立重建；远期/终值参数；企业价值到股权及每股价值；比较股价。并列估值分别追踪，没有合成公式不编综合目标价。
4. **模型没有告诉我们什么**：区分未记录的假设理由、未建模的经济驱动、尚未追清的依赖、已查实的冲突及其影响。不要把这四类都写成“数据不足”。

## 如何追到真正输入

- **角色按依赖方向判断，不按行名或单元格形式判断。** “原模型判断”指模型采用的未来假设、预测规则或调整；“计算结果”指给定上游判断后算出的量。历史观测不归为预测判断；引用的外部预测注明来源，不冒称本分析师原创判断。一个结果也可能是下游模块的输入，需标“由上游计算后引用”，不能重复算成新的独立判断。
- 将经济角色与实现方式分开：硬填历史值不是预测判断；公式中“上年毛利率＋20基点”包含判断的是20基点调整，毛利率水平仍由公式产生；相同指标在不同年份、业务或模块可有不同角色。允许“判断与计算混合”及“暂无法判定”，不强行二选一。

| 实际依赖方向的例子 | 原模型判断 | 计算结果 |
|---|---|---|
| 上年收入×（1＋设定增长率）→本年收入 | 设定的增长率 | 本年收入 |
| 门店预测→加总公司收入→倒算公司增长率 | 门店预测及其更上游假设，继续追到实际起点 | 公司收入、公司增长率 |
| 收入×（1－设定毛利率）→成本 | 毛利率假设；若毛利率也由上游算出则继续追踪 | 成本 |
| 材料、人工、租金预测→总成本→毛利率 | 各成本预测及实际采用的单价、用量等上游假设 | 总成本、毛利率 |

以上是识别方向的对照，不是指定模型必须采用其中一种。混合建模按业务/期间分别说明，不能看到“收入增长率”或“毛利率”一行就认定它是判断。

- 同时读取公式与缓存、时间表头、必要样式和批注。E、颜色、公式及引用共同判断历史/预测；颜色或是否硬填都不能单独定性。
- 将重要节点区分为：**直接设定**（含公式内常数）、**引用沿用**、**公式计算**、**倒算/残差**、**来源未解析**。公式单元格也可能包含独立假设，不能把所有公式一律视作被动结果。
- 每个关键输入记期间、值/单位、设置方式、上游来源和下游输出；追到可解释的止点：历史观测、独立参数、可定位的外部链接或明确未解析节点。批注若给依据，保留作者/日期/来源（有则记），不把批注当正确性证明。
- 连续期间至少核查预测首期、相邻期及公式/颜色改变处。四季度同为12%必须查清是四个常数，还是首季常数、后季链接；相同值不证明沿用，复制相同常数也不证明有四次独立经济判断。
- 汇率项区分直接设定的收入影响、沿用影响、由汇率预测及权重计算；保持原加法/乘法。上年同期基数继续追一层，防止把前一年预测当实际。
- 年度增长区分独立输入、季度收入加总后同比倒算、季度增速平均；不把看起来相同的结果当同一公式。
- 营业利润变化沿本模型的实际层级追到上游判断，例如地区增长、门店预测、成本明细或费用规则；不预设增长率与毛利率必为输入。讲清依赖与方向，不强行把每项假设贡献精确量化；若做贡献归因，说明固定条件、顺序及交互，避免重复相加。
- DCF明确哪些年度/项目引用主表，哪些直接设定或另行计算；同名科目/同值不等于有链接。说明利润率、再投资、营运资金、折现率是否真正进入计算，而非仅在表内出现。

## 可检查的验收标准

理解验收检查交付是否解释了原模型，不判定公司好坏。逐项记录“通过 / 未通过 / 无法验证 / 不适用”、证据与缺口；不适用必须说明范围原因。

| 标准 | 通过所需证据 |
|---|---|
| U1 真正输入 | 能按实际依赖区分原模型判断、历史事实、引用与计算结果，解释同名指标为何在本模型中扮演该角色；不能只交颜色、公式或硬填分类。关键输入已追到止点，连续期间的沿用关系有原公式证明。 |
| U2 基数与期间 | 能解释历史/预测基数、币种与单位、汇率处理、季度到全年及增长率的方向，不以最新实际覆盖旧基线。 |
| U3 利润依赖 | 能解释本模型采用毛利率反推、成本明细汇总或混合逻辑，从实际判断接到营业利润、税项、归母利润和EPS；不将计算出的毛利率误标独立假设，会计桥不是唯一说明。 |
| U4 现金流与定价 | 能指出必要投入与现金流关系、估值和主预测的接点/断点、独立远期参数、价值桥及真正采用的股价/折现率。 |
| U5 路径复现 | 对适用的收入、利润、现金流/定价链各选一条代表路径，用原值局部复算并与缓存比较；记录原公式、结果、差额、单位和容差依据。另选至少一个真正输入做小幅扰动，检查下游变化方向和沿用传播，声明固定条件与复算范围。 |
| U6 三层分离 | “Excel怎么算”“模型记录了什么理由”“外部证据是否支持”可分别读取；前两层没有被实际兑现、市场观点或研究者推断代替。 |

复算可用只读导出后的Python或可用计算引擎，不修改原表。不得只把缓存值相乘便声称重算整条链；从选定输入开始重算实际受影响的公式。只检查了代表路径也不声称全表已验收。外链、宏、数据表或不支持函数阻断时记“无法验证”并限定输出，不补假公式。

**验收A：模型理解。** 核心适用项有可复核证据才通过。模型明确硬填但没写理由，不妨碍理解通过；模型公式存在错误但已追清、复现并披露，也不等于没有理解。核心输入链仍未解析、复算差异未解释或把实际/市场代替输入链时，不通过完整模型理解。已理解的部分仍可交付。

**验收B：投资判断。** A之后才检验现实经营条件、正反证据、市场预期、估值合理性和改判条件。A通过不代表B通过，也不代表原模型正确。A未通过时可继续不依赖缺失链的研究，但受影响判断标待验证，不能以完整投资报告或结构校验替代A。

这是agent执行的两个质量关口，不是要求用户逐步批准。资料可用时持续完成授权工作；没有工作簿则A标不适用，不能声称理解了原Excel模型。只要求模型说明时止于A，不启动市场研究或强制生成三图。
