# Excel 估值取证与核验

只在估值报告或估值结果核验时使用；建模机制用 [模型理解](../../pe-financial-model-understanding/SKILL.md)。先遵循 [reader](../../pe-financial-model-reader/SKILL.md)，此处不另设一套读表流程。

- 锁定原文件版本与 doc_id。项目取证、附件取证、受限后台研究使用各自入口，不为了报告而跨入口拼接。
- 项目估值输出可用 `pe_valuation_output_locate` 按原文 query 搜索，返回 matches 而非已选主输出。对相关命中补读表头和公式，并按 next_offset 继续；非主表、隐藏区域同样可能有重要结果。完整文字搜索不证明输出覆盖完整。
- 核对每个候选的期间、币种、单位、用途、价格基准和计算链。无法消解的多方法/多价格冲突分别保留，不能选第一个就忽略其他结果。
- `pe_valuation_date_resolve` 核验传入的日期与标签证据。日期的业务角色仍需判断；模型股价日、报告日、预测期和财务截止日不得互换。
- `pe_model_validate` 是结构、缓存和外链检查，不是公式图或财务逻辑审计。trace 不完整时按 reader 继续取证；外链/动态引用不可假装已解开。
- 直接核对范围内的原始公式、缓存、标签、number_format、批注。期间与单位由这些原文及跨表来源支持，不依赖工具替分析师推断。
- 对影响所问结果的冲突和未知项如实说明。不能为报告简洁而隐藏，也不把与答案无关的全表告警堆进结论。未定位不等于不存在。
