# 估值模型详细分析参考

在需要深入解释估值方法、经营传导、同业比较或敏感性时读取相关部分。输入角色和模型说明复用 [模型说明与理解验收](../../valuation-model-review/references/model-understanding.md)；估值桥、基准复现和两类敏感性按 [共同计算规则](../../valuation-model-review/references/valuation-methods.md)，不另设一套默认变量或矩阵。

## 从已有模型说明接续

先定位所问估值输出的期间、单位、价格基准及实际方法，再解释该方法中少数关键假设如何影响盈利、现金流与价格。多方法并列且没有权重时分别说明，不自行指定主目标价。

复用说明中已核实的经营链和路径证据，仅补查影响当前问题的断点。说明模块作用、关键输入、必要公式与结果含义，不逐格复述，也不把可选的行业/量价/门店拆分强套给原模型。

模型记录的方法或选值理由与研究者对合理性的评价分开。公式不能证明分析师动机；缺理由就列缺口或明确标注解释候选。用户只问建模思路时不扩展全面审计或市场研究。

## 按方法解释含义

- **相对估值**：讲清目标年度与盈利/收入口径、倍数来源及适用性；原因未在模型记录时如实说明。同业、历史区间与溢价须有来源及可比基础。
- **DCF**：解释预测期现金流、折现参数与终值各自作用，利用经核验的终值占比说明长期参数依赖；不以表内出现某个WACC就认定它进入了估值。
- **SOTP**：说明各业务为何用相应方法，以及分部结果如何经集团调整汇总；不重复叙述已经交付的价值桥计算。

## 按问题选择敏感性

问“哪个假设影响模型”时使用原模型输入敏感性；问“给定EPS和倍数时价格是多少”时使用价格条件对照。已有表内情景也须按实际公式分类；补充测算标明假设及固定条件，不冒充原表结果。

计算遵循共同规则。缺完整输入时只说明已证实路径和量化缺口；简单问答不自动展开矩阵，复杂多变量重算按用户范围执行，不修改原工作簿。

## 报告与风险

需要整体估值报告时沿 [回答结构](answer-structure.md) 及对应工具流程交付，不再追加另一套完整报告。缺评级、同业、DCF或敏感性数据时不机械补齐。

风险落到具体假设失效及其传导路径。“模型依赖高增长兑现”不等于“高估值合理”，后者需要额外证据；远期倍数下降本身也不构成支持。
