# 估值模型详细分析参考

整体分析需要深入解释估值方法、经营传导或敏感性时使用。单项简答只取相关部分，不另写一份报告。

## 使用公共规则

输入角色、预测依赖及说明交接遵循 [模型说明与理解验收](../../valuation-model-review/references/model-understanding.md)；基准复现、价值桥、估值方法和两类敏感性遵循 [估值公共规则](../../valuation-model-review/references/valuation-methods.md)。已注入的参考直接复用，不重复读表。

## 📝 驱动发现与重算

用户问哪些假设最影响估值时，从已确认的输出调用 `pe_driver_discover`，结合期间和原公式核实候选角色，再对适用输入调用 `pe_driver_sensitivity`。工具在隔离副本中逐项扰动，重算中间公式与估值输出；不得覆盖公式结果冒充原模型输入情景。

结构候选顺序不是敏感性排名。按公共规则核对原基准、扰动依据与实际覆盖范围后，才解释已测试输入的估值影响；单变量结果不能外推为多变量联合情景。正文优先解释会改变结论的少数驱动及证据薄弱的假设，传播明细、未测项和运行记录保留在审计附件。

## 解释职责

1. 定位与问题相关的输出及实际方法，说明目标期间、价格基准和最短可核验公式。搜索命中不等于已认证输出；并列方法按原关系分别解释，不擅选主目标价。
2. 承接已完成的模型说明，从用户关心的输出解释真实业务输入如何传到盈利、现金流和估值。只选实际建模的模块，不强套量价、门店或市场份额路径，不用最后一步乘法替代整体模型说明。
3. 解释模型使用的方法及参数所代表的条件。模型记录的选值理由与研究者推断分开；用户只问模型思路时不自动评判市场定价或扩展全面审核。
4. 问敏感性时，明确回答的是原模型输入扰动还是价格条件对照。可解释原表情景、执行有足够证据的补充计算或仅给方向；没有原表矩阵不代表不存在敏感变量，输入不足也不能编造矩阵。按公共规则报告固定条件与实际复算范围。

## 展开报告

沿 [回答结构](answer-structure.md) 按用户问题组织模型逻辑、关键驱动、预测与敏感性、风险；不追加第二套报告。需要项目整体估值交付时仍执行 [报告流程](../../pe-valuation-report/SKILL.md) 的事实与计算校验，不能用本参考替代工具契约。

解释集中于少数有引用的关键数字、必要公式及含义，避免重复预测表。风险落到实际假设和传导路径；“依赖高增长兑现”不等于“高估值合理”。模型事实、分析判断及条件反推分别标识；评级、同业比较或参数理由缺乏来源时不补成事实。
