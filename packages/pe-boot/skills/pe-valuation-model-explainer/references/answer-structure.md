# 估值分析回答结构

整体模型分析或用户明确要求简答时读取对应部分；单项指标直接回答。

有原始 Excel 的整体分析：若尚未加载 pe-valuation-report，先用 pe_load_capability 加载它。下方结构用于准备报告输入；完成取证后调用 pe_valuation_report，只有返回 ready 才能原样交付 rendered_report。不要直接按模板自行写最终数值报告，也不要因尚未调用报告工具而结束任务。

## 回答详略

- “分析这份估值模型”“分析估值报告”“整体逻辑是什么”等一般请求默认使用下方四段结构，保留关键数据和因果解释，不再限制为 3—5 行或 250 字。
- 用户只问目标价、估值日或某个指标时，只回答该项，不套用完整模板。
- 只有用户明确要求“只要结论”“只给结果”“简短回答”时，才收敛为 3—5 个短行：目标价、参考价格与涨跌幅、其他估值结果。
- 用户要求“详细分析”“展开推导”或具体情景测算时，在四段结构内加深所问部分，不额外拼接一套六章报告。
- 表格用于集中比较关键指标和预测期间，同一表格只展示一次；正文解释变化原因及估值影响，不逐项重复表格数字，也不在结尾再次复述整篇报告。根据证据和用户问题控制篇幅，不为凑齐模板增加无关内容。
- 回答详略不改变内部核验和引用要求。报告只展示有依据的内容，省略“币种未确认”“日期未确认”“模型未提供”等说明及缺失模块的空标题。未知状态和冲突留在工具结果中，不猜测、不把未验证项写成已确认事实。多个年度或方法的结果分别展示，不擅自选定主目标价。用户明确要求审计或追问某项是否确认时，再说明对应证据状态。
- 用户提供的示例只用于参考结构与表达层次，不把示例中的公司、评级、数字、投资叙事或情景测算当作当前模型事实。

## 默认整体结构

### 一、模型逻辑框架

先用 1—2 句话说明模型的核心判断、主估值方法和估值年份，再给一张紧凑的“项目—数值/口径”表：

- 估值日、参考股价及价格日期、目标价、对应上涨/下跌空间；
- 主估值方法、关键倍数或折现参数及最短目标价公式；
- 模型确实提供时，再列旧目标价及调整幅度、评级、其他方法的估值结果或远期隐含倍数。

明确参考股价来自模型填写值、缓存还是有日期的市场数据；每个涨跌幅绑定同一目标价和价格基准。缺失的评级、旧目标价、估值日或其他估值方法直接省略。方法主次、交叉验证关系或权重也需有依据。

### 二、核心驱动因素

选择支撑估值的 2—4 个关键驱动，例如收入增长及其来源、毛利率与费用率、盈利拐点、资本开支/营运资金、目标倍数。每个驱动用“关键假设与数据 → 对盈利或现金流的影响 → 对估值的意义”解释。

集中展示少数关键期间和指标，必要时用一张预测表；不要穷举每个地区、品类和年份。区分收入、利润率、归母净利润与 EPS 的口径，只有公式或模型说明支持时才认定某项假设驱动下游。高增长消化估值等判断写成模型依赖的假设，不直接认定估值合理。

### 三、盈利预测与敏感性分析

按主估值方法选择 EPS、EBITDA 或 FCF，展示关键预测期间、增速或盈利拐点及其到目标价的关系。已有预测表能覆盖时直接引用其结论，不重复制表。

- 有原表敏感性结果：说明基准值、变量范围和实际结果；只在数据支持时比较敏感程度。
- 无原表敏感性结果：省略缺失说明，按已有公式解释关键经营变量和估值变量影响盈利、现金流和目标价的路径。
- 可以基于已核验的公式与完整输入做简单补充测算，但必须标记“假设情景，非原表结果”，说明变动变量、保持不变的条件及计算口径；测算前读取详细分析参考。税率、股数或单位等必要输入缺失时只给方向，不编造 EPS 或目标价变动数值。不自动把收入变化比例等同于 EPS 变化比例。
- 不凭空设置并冠以“同业均值”“合理估值”“最敏感”等标签；需要同期间、同口径的比较证据或实际测算支持。

### 四、模型核心风险点

选择 2—4 项与关键假设直接相关的风险，用“哪项假设可能偏离 → 如何影响盈利/现金流 → 如何影响估值”表述。保留有依据的经营和估值风险，不用未确认日期、缺失模块或工具核验状态填充风险段落。

四段是整体分析的参考结构，不是填空要求。材料不足的部分直接省略；只问单项时省略无关章节，不机械套入 EPS、DCF、可比公司或评级。

## 用户明确要求简答时

```markdown
- 目标价：【货币及每股金额】，基于【目标年度 EPS × P/E，或其他主方法的关键依据】。【证据引用】
- 上涨/下跌空间：【比例】，相对【明确的参考价格；说明是模型填写价或行情缓存，不冒充实时股价】。【证据引用】
- 其他估值：【模型实际存在的其他方法及每股结果；不存在则省略本行】。【证据引用】
```

按实际情况省略无关项，不输出占位文字。多个年度或方法结果分别展示，不为凑齐模板选定一个主目标价或添加未确认说明。主输出缺失时不编造涨跌幅或其他估值结果。只问一个指标时，不使用上述完整模板。
