# 📝 估值报告表达

整体估值报告才使用 [报告流程](../../pe-valuation-report/SKILL.md)。普通模型逻辑问答和投资框架不要套此格式。

先复用 [模型说明与理解验收](../../valuation-model-review/references/model-understanding.md) 的完整模型说明：结构概览，收入，成本与利润，现金流与估值，以及未知项；再按用户请求解释估值含义、敏感性与风险。前置说明不能缩成目标价及最短乘法。后续分析的组织与篇幅按证据和问题决定，不预设“主方法”。

- 关键数字集中展示一次，带期间、单位和来源；多个价格基准分别说明其用途，不能拼成一个涨跌幅。
- 输入角色沿用模型说明；数字、模型记载的理由与研究者判断分别呈现。不能因模型预测增长就认定公司增长有保障。
- 简短问答只答所问；完整报告的篇幅由证据和问题决定。
- 敏感性按 [估值公共规则](../../valuation-model-review/references/valuation-methods.md) 分类和标注；没有量化依据时只解释已证实路径。需要图表时用 [图表公共规则](../../valuation-model-review/references/chart-quality.md)，不因报告格式强制凑图。
- 只陈述证据支持的主次、评级、日期和单位。影响解释的缺失与冲突要说清；无关缺项不凑空标题。
- 风险对应具体假设如何失效，不以通用行业风险填空。分析师的动机需要另有证据，模型公式本身不能证明。
