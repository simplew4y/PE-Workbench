# 估值模型思路拆解

先核验结果及依据，再解释关键假设如何支撑估值。按实际方法建立计算链，例如 EPS × P/E → 每股目标价，或 FCF 折现 → 企业价值 → 股权价值 ÷ 稀释股数 → 每股价值。

## 按任务读取

- **原始 Excel 可用**：先读 [工作簿核验](references/workbook-verification.md)，再按其中步骤锁定 doc_id、定位输出、核验日期、追踪公式并检查缓存。
- **只有截图、公式摘录或他人分析**：仅分析可见证据，区分原模型事实与转述；不编造 doc_id、单元格、引用、工具结果或工作簿核验。原文件可用时回到原文件取证。
- **整体分析**：有原始 Excel 时，立即调用 pe_load_capability，capabilities 包含 pe-valuation-report（并保留仍需要的其他流程）；它会一并加载模型取证、回答结构和报告交付要求。完成取证后必须实际调用 pe_valuation_report，修正可修复问题直至 ready，再原样交付 rendered_report。仅仅读取回答结构或完成模型核验不等于生成报告，不能以“尚未取得校验结果”提前结束。仅当加载工具不可用时，才从 available_skills 读取报告 skill。默认按“模型逻辑框架、核心驱动因素、盈利预测与敏感性分析、模型核心风险点”组织，不为填满结构增加无依据的内容。
- **单项指标或公式**：直接回答所问；有原始 Excel 时仍完成与结论相关的取证，不加载整体报告流程。用户明确要求简答时读回答结构中的简答部分。
- **深入解释经营假设、估值方法、同业比较或补充情景测算**：读 [详细分析参考](references/detailed-analysis.md)，只使用相关部分。

## 分析边界

明确模型事实、分析判断和补充假设；模型缓存价不是实时行情。敏感性测算需要已核验公式、完整输入、一致单位及固定条件，标记“假设情景，非原表结果”；输入不足时只解释有依据的方向，不编造 EPS 变化或敏感性排名。用户示例只提供结构，不提供当前模型事实。

整体分析不是默认简答。报告省略未确认元数据、缺失模块和空标题，保留内部核验状态；用户要求审计时解释。多个方法或年度分别展示，不擅自选主目标价。除非明确要求保存研究成果，否则只在对话中回答，不创建 Memo 或 Research Note。

## 证据与异常

- 每个重要数字、公式和模型结构后放置检索工具返回的准确 `markdown_citation`；不得展示裸露的 `source:` ID。
- 保留引用中的 `#pe-source?evidence_id=` 片段；界面将其显示为带无障碍来源标签的紧凑角标，点击仍可查看原始证据。不得手写编号、改成普通网址或用来源集合替代逐项引用。
- `pe_valuation_report` 会将引用的显示文字缩短为“来源”，保留完整证据地址；直接交付工具生成的链接，不在正文逐次展开长文件名。币种等共用口径在表格旁统一说明，单项冲突另行标注。
- 引用尽量落到目标价、经营假设、利润预测和估值公式所在的具体工作表与单元格或范围。
- 同一处引用不要支持超出其实际内容的结论；关键计算链涉及多个输入时分别引用。
- 业务驱动和经济含义必须有模型文字或公式关系支持；把分析推断明确标出，不将表格中并列的指标直接解释为因果关系。
- 若发现 `#REF!`、`#NAME?`、外部链接失效、公式缓存缺失、循环引用或单位异常，内部核对影响范围，不把异常项当作有效数据。报告保留有效结果；详细异常说明用于用户明确要求的审计。
- 默认使用中文，面向有基础财务知识但不一定熟悉模型公式的读者。
