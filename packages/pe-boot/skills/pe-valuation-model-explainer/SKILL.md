# 估值模型思路拆解

先核验估值结果及其计算依据，再解释“关键假设如何支撑估值”。整体分析同时给出结果、关键驱动和必要风险，按模型实际方法建立计算链：

```text
P/E：目标年度 EPS × 目标 P/E → 每股目标价
DCF：自由现金流折现 → 企业价值 → 股权价值 ÷ 稀释后股数 → 每股价值
```

不逐单元格复述，也不预测股价一定上涨或下跌。除非用户明确要求保存研究成果，否则只在当前对话中回答，不创建 Memo 或 Research Note。

## 回答详略

- “分析这份估值模型”“分析估值报告”“整体逻辑是什么”等一般请求默认使用下方四段结构，保留关键数据和因果解释，不再限制为 3—5 行或 250 字。
- 用户只问目标价、估值日或某个指标时，只回答该项，不套用完整模板。
- 只有用户明确要求“只要结论”“只给结果”“简短回答”时，才收敛为 3—5 个短行：目标价、参考价格与涨跌幅、其他估值结果及必要提示。
- 用户要求“详细分析”“展开推导”或具体情景测算时，在四段结构内加深所问部分，不额外拼接一套六章报告。
- 表格用于集中比较关键指标和预测期间，同一表格只展示一次；正文解释变化原因及估值影响，不逐项重复表格数字，也不在结尾再次复述整篇报告。根据证据和用户问题控制篇幅，不为凑齐模板增加无关内容。
- 回答详略不改变工具核验和引用要求。估值日未确认、主输出有歧义、价格基准冲突或计算未经验证时，保留影响结论的必要提示，不隐瞒冲突候选或重要限制。
- 用户提供的示例只用于参考结构与表达层次，不把示例中的公司、评级、数字、投资叙事或情景测算当作当前模型事实。

## 开始前核验

若用户只提供模型截图、公式摘录或他人分析，先核对可见内容、期间、单位和来源，区分原模型信息与转述或分析推断。只有能访问原始 Excel 时才执行下列工作簿工具核验；没有原文件时明确无法验证完整公式链、缓存和估值日，不编造 `doc_id`、单元格、引用或工具结果，也不把他人的结论视为已经核验。原文件可用时回到该文件取证。

1. 先调用 `pe_workbook_inspect`。如果存在多个工作簿，必须锁定一个 `doc_id` 后才能分析；无法确定权威文件时列出冲突，不替用户选择。
2. 后续所有 Excel 检索和取数必须使用同一个 `doc_id`。不得把不同工作簿中的指标静默拼接。
3. 收集公司或项目、可能的日期、货币、单位、当前股价、目标价、目标年份和预测期。此时不要把最大日期、预测年份、报告日或文件时间直接认定为估值日。
4. 调用 `pe_valuation_output_locate` 生成和评分估值输出候选，不要用通用搜索结果或第一个关键词命中替代它。`selected` 表示确定性规则选出了首选候选，但不表示数值已经重算验证；`ambiguous` 时保留全部 `conflicting_candidate_ids`，分别检查公式链，不能擅自选择第一名；`missing` 时使用 `pe_document_open` 打开同一 `doc_id`，再用 pi 原生 `grep` / `read` 检查该文件的文字视图，并明确仍未定位主输出。
5. 定位器返回 `selected` 后，调用 `pe_valuation_date_resolve`，将 `selected_output.candidate_id`、`selected_output.sheet_name`、`selected_output.cell_ref` 分别传入 `output_candidate_id`、`output_sheet`、`output_cell_ref`。如果输出仍为 `ambiguous`，应使用 `conflicting_outputs` 分别在每个冲突输出上下文中解析日期，不得把不同输出的日期合并成一个全局估值日。分别保留估值日、市场价格日、财务数据截止日、报告日、模型更新时间、目标期限和预测期。
6. 只有 `pe_valuation_date_resolve.status=verified` 才能写“已确认估值日”。`inferred` 必须披露推断依据；`ambiguous` 必须列出冲突日期；`missing` 必须写明模型无法确定估值日。默认不得启用文件时间 fallback。
   工作簿由上传后台准备；读取工具等待准备完成，缓存缺失时自动重建。解析失败时说明无法读取，不得退回按文件名或文件时间猜测。
7. 调用 `pe_formula_trace` 反向追踪上游。对链条中的关键范围使用 `pe_excel_range` 精确读取公式、缓存值、数字格式、期间和单位。
8. 调用 `pe_model_validate` 检查缓存覆盖、公式断链、外链、错误值和指标质量。必须区分 `structural_status` 与 `calculation_validation.status`；简答用一句话说明影响结论的核验限制，详细核验报告再分别列出状态，不得把结构通过表述为数值已经重算验证。
9. `pe_source_detail` 继续用于核验检索得到的 PDF 页或 Excel 单元格范围，但不得用局部窗口代替公式追踪。
10. 若 `pe_formula_trace.complete` 为 false，必须核对外链、未解析引用、错误引用、循环、深度限制或节点限制。简答披露影响当前结论的断链限制，用户要求详细核验时再列明各项。不得自行补全缺失链条。
11. `formula_cache_status=present` 只表示缓存存在，不表示刚刚重算。若 `calculation_validation.status` 不是已验证状态，不得声称数值已经重算验证。缓存缺失或异常时，不得把公式文本或推算值写成模型原始计算值。

用户所问的结果缺失时，直接写明“模型未提供”或“无法验证”及必要原因。不要机械补齐不存在的数字、公式、估值方法或敏感性结果；简答不为未请求的缺失模块保留空标题。

## 分析参考

内部完成上述取数、日期解析、公式追踪和模型核验；对外按下方四段结构解释结果，不逐条输出工具调用过程。

## 证据与异常

- 每个重要数字、公式和模型结构后放置检索工具返回的准确 `markdown_citation`；不得展示裸露的 `source:` ID。
- 保留引用中的 `#pe-source?evidence_id=` 片段；界面将其显示为带无障碍来源标签的紧凑角标，点击仍可查看原始证据。不得手写编号、改成普通网址或用来源集合替代逐项引用。
- 引用尽量落到目标价、经营假设、利润预测和估值公式所在的具体工作表与单元格或范围。
- 同一处引用不要支持超出其实际内容的结论；关键计算链涉及多个输入时分别引用。
- 业务驱动和经济含义必须有模型文字或公式关系支持；把分析推断明确标出，不将表格中并列的指标直接解释为因果关系。
- 若发现 `#REF!`、`#NAME?`、外部链接失效、公式缓存缺失、循环引用或单位异常，简要说明其对结论的影响。非关键历史区间错误不应掩盖主要估值链条。
- 默认使用中文，面向有基础财务知识但不一定熟悉模型公式的读者。

## 默认整体结构

### 一、模型逻辑框架

先用 1—2 句话说明模型的核心判断、主估值方法和估值年份，再给一张紧凑的“项目—数值/口径”表：

- 估值日、参考股价及价格日期、目标价、对应上涨/下跌空间；
- 主估值方法、关键倍数或折现参数及最短目标价公式；
- 模型确实提供时，再列旧目标价及调整幅度、评级、其他方法的估值结果或远期隐含倍数。

明确参考股价来自模型填写值、缓存还是有日期的市场数据；每个涨跌幅绑定同一目标价和价格基准。缺失的评级、旧目标价或其他估值方法不补齐；估值日和主输出无法确定时必须说明。方法主次、交叉验证关系或权重也需有依据。

### 二、核心驱动因素

选择支撑估值的 2—4 个关键驱动，例如收入增长及其来源、毛利率与费用率、盈利拐点、资本开支/营运资金、目标倍数。每个驱动用“关键假设与数据 → 对盈利或现金流的影响 → 对估值的意义”解释。

集中展示少数关键期间和指标，必要时用一张预测表；不要穷举每个地区、品类和年份。区分收入、利润率、归母净利润与 EPS 的口径，只有公式或模型说明支持时才认定某项假设驱动下游。高增长消化估值等判断写成模型依赖的假设，不直接认定估值合理。

### 三、盈利预测与敏感性分析

按主估值方法选择 EPS、EBITDA 或 FCF，展示关键预测期间、增速或盈利拐点及其到目标价的关系。已有预测表能覆盖时直接引用其结论，不重复制表。

- 有原表敏感性结果：说明基准值、变量范围和实际结果；只在数据支持时比较敏感程度。
- 无原表敏感性结果：明确“模型未提供独立敏感性表”，指出关键经营变量和估值变量，以及影响盈利/现金流和目标价的路径。
- 可以基于已核验的公式与完整输入做简单补充测算，但必须标记“假设情景，非原表结果”，说明变动变量、保持不变的条件及计算口径；测算前读取详细分析参考。税率、股数或单位等必要输入缺失时只给方向，不编造 EPS 或目标价变动数值。不自动把收入变化比例等同于 EPS 变化比例。
- 不凭空设置并冠以“同业均值”“合理估值”“最敏感”等标签；需要同期间、同口径的比较证据或实际测算支持。

### 四、模型核心风险点

选择 2—4 项与关键假设直接相关的风险，用“哪项假设可能偏离 → 如何影响盈利/现金流 → 如何影响估值”表述。将估值日、价格冲突、公式或缓存限制等影响结果的数据质量问题简要列出，不重复整段技术日志。

四段是整体分析的参考结构，不是填空要求。材料不足的部分简要说明无法验证；只问单项时省略无关章节，不机械套入 EPS、DCF、可比公司或评级。
