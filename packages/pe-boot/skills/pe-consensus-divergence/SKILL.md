# 项目样本共识与分歧

## 工作流

1. 用 `pe_consensus_cards` 读取当前项目已计算的卡片，设置 `include_sources=true`；按需传 `item_key`、`card_types`，增加 `limit` 获取更多卡片（最多 100）。
2. 先检查 `status`、`stale`、`built_at` 和 `coverage`。尚未分析、分析失败或覆盖不全时说明缺口；旧快照不能当作最新结果。没有卡片不代表机构没有分歧。
3. 对关键结论，用返回的引文和来源核对；需要上下文时用 `pe_pdf_read` 或 `pe_source_detail`，需要补查资料时用 `pe_pdf_list`、`pe_pdf_search`。Excel 辅助核验用 `pe_workbook_inspect`、`pe_excel_range`，不能把它冒充已纳入 PDF 机构统计的样本。
4. 回答先给结论，再说明覆盖机构、期间与口径、乐观与谨慎方的理由、近期变化及待验证因素。每个重要事实附原样 `sources[].citations[]`，补查工具则用其 `markdown_citation`；无法解析的引用先说明并重新核验。

## 统计与解释边界

- 共识只代表本项目资料，不是全市场一致预期。按独立机构计票，同一机构同一问题/期间只取最新可用观点；公司指引单独展示。
- 未提及、未找到已核验观点、不具可比性都不等于反对。分开说明 `stats.sample` 中的立场样本和 `stats.n` 的数值可比样本；不同单位、币种、期间、指标或明确口径不混算。
- 中位数、均值、区间、四分位距（IQR）和中位绝对偏差（MAD）使用工具计算值。IQR/MAD 衡量离散程度，不是置信区间；不要自行改写聚合数值。
- 动态问题沿用入库时的问题清单。仅一家机构的发现可作为单一观点；至少两家独立机构、有不同原始证据时，才称为样本共同关注的问题。旧资料未按新问题核验时，不声称已完成回填。
- 区分资料明说的事实、可复现的推导和分析推测。没有外部市场基准，不能由机构分歧直接得出“市场错误定价”。

## 完成条件

给出可追溯的比较和覆盖限制即可；本 Skill 不生成 Memo 或 Research Note，不修改数据库。观点提取、问题归并和卡片计算由上传后的分析流程完成；当前没有 Agent 侧构建、审核或历史回填工具。
