# Falsification & Monitoring

开始前读取 [共同数据约定](../investment-framework-builder/references/state-contract.md)。完整流程只更新指定状态字段和分析附件，不各写一篇完整报告；单独调用时可返回该模块的中文结果。保留来源与稳定 ID。

## 输入与输出

输入：theses、assumptions、sensitivities、evidence、此前状态和新增资料。输出：monitoring、changes、gaps、第三张图；不擅自更改原判断或启动调度。

- 每项监控引用thesis_ids及assumption_ids，给可信数据源、期间口径、检查频率、预警、失效及触发后复核动作。承接模型说明区分独立输入与派生结果；例如跟踪全年EPS可验证结果，但不自动解释地区增长或税率假设为何偏离。
- 分清单期偏差、持续假设偏离和核心机制被推翻；阈值依据历史波动、机制或估值影响，不机械设10%。没有数值依据允许定性事件或明确待确定。
- 频率匹配发布节奏。触发意味着核验、修订或重算，不是自动交易。用户明确请求定时任务时才调用可用调度工具，不能只写规则便声称已启动。
- 版本记录原判断、新证据、影响的逻辑、修订理由及新状态；仅无关措辞变化不触发改判。首次报告无前版就不造变化；证据增加但判断未变需明确。
- 负责关键变量追踪图，按 [共同图表规范](../valuation-model-review/references/report-charts.md) 承接重点变量；已有同版本、同范围图可复用，单项任务按范围决定是否需要图。
- 对无法直接观测的倍数或折现率使用有来源参考，不能称为经营实际。条件反推注明固定其他假设，不能冒充新预测。

模块表：逻辑｜假设与指标｜来源/频率｜预警｜失效｜复核动作。changes：旧判断｜新证据｜新判断｜原因。
