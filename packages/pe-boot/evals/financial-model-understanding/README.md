## 怎么判

逐题核验 must；任一 fatal 命中则失败。允许不同地区或公式路径，只要真实、相关且追到声称的程度。不用关键词命中或章节齐全代替判断。

- **方向和假设**：是否区分输入、计算结果、继承假设，追踪是否真的支持覆盖范围。
- **证据忠实**：坐标/公式/缓存/单位和原表一致；不能拿预测数证明预测理由。
- **不确定性**：重要断点、外链、混合期间、价格冲突有没有说清。
- **研究用途**：能否提出可验证且可能改变判断的问题，而非生成公司介绍。

`check_evidence.py --workbook /path/to/model.xlsm` 通过项目 reader 核实少数关键公式和值。它是答案基础的回归检查，**不是 skill 分数**。脚本不存整表，不读取任何 API key。

行为测试应保留实际回答及核验结果。人工/独立评审写每条 must 的证据，结论用通过/部分通过/失败，避免没有依据的精细数字分数。发布前再用未进入本测试集的不同公司模型检验。
