# 项目研究积累：第一版

## 2026-09-21 追加：进展概览与导出

- 新增「研究到哪里了」：最近更新，以及已确认、待研究、待核实三类记录各最近 3 项；点击条目定位对应卡片。归档记录不计入，并提示成果的资料引用缺口。
- 新增「导出研究进展」：导出当前项目全部未归档记录的 Markdown，包含状态、版本、时间、原始摘录、会话／回答标识与资料引用。不受搜索或勾选范围影响，不包含其他项目或归档记录。
- 概览按保存状态整理，不额外调用模型，不生成新的投资结论或自动判断研究已完成。模型摘要仍未实现。
- 「回到原回答」通过应用内状态直接切换来源会话，必要时切换到回答所在会话分支、展开历史消息，并定位回答，不再整页刷新；支持 CSS 高亮的浏览器会精确高亮原摘录，其余浏览器仍会突出并定位整条回答。
- 编辑卡片或新增研究问题时，可以关联最新投资框架中的论点、假设、指标、问题或事件。关联随卡片版本持久化；框架条目被移除后显示失效提示，但不会自动改写框架。编辑时会自动滚动到表单，各状态使用不同颜色标识。
- 保存回答摘录时只关联选区实际覆盖的资料引用；卡片可查看各版本的字段变化，并把历史标题、内容和框架关联复制为新版本，恢复后重新进入待核实／待研究。

研究员可以把一次对话中的成果和未解决问题保留在公司项目下，下次打开项目时查看研究进展，再选择必要的背景继续研究。

## 使用方式

1. 打开一个公司项目。回答完成后，选中有价值的文字，在选区旁的浮层中点击「保存研究成果」，填写标题并确认选中摘录。只保存选中文字，不回退保存整段回答；未选中文字时不显示保存按钮。
2. 在选区浮层中点击「记录待研究问题」，留下下一次需要验证的问题及其摘录来源；也可以在右侧「研究积累」中新增问题，并关联当前勾选的研究卡片。Esc 可关闭浮层，选中文字后可用 Tab 和回车进入操作。
3. 在「研究积累」中查看研究成果、待研究问题和待核实成果数量，搜索、筛选卡片，或进入投资框架。每张卡片保留保存时间、更新时间、原回答摘录、来源会话及可定位的资料入口；点击来源链接会定位并高亮原摘录。
4. 核实后可以标记「已人工确认」或「已解决」。编辑时可关联最新投资框架条目；修改内容会重新进入待核实或待研究状态。暂时不用的卡片可以归档并恢复。
5. 勾选卡片，填写本次研究问题，点击「新会话继续研究」。系统使用当前模型和工具配置创建新会话，将选定版本的内容、状态和资料入口作为明确可见的研究背景。

## 三分钟演示

准备一个已有资料和历史回答的公司项目。

- 在回答中选中一段关于海外收入和盈利质量的文字，通过浮层保存卡片；展开原回答与资料入口，说明结论可以回到原始出处。
- 核查后标记已人工确认，再新增「海外收入增长是否转化为经营现金流？」问题，并关联该卡片。
- 刷新页面，展示两项记录仍在；切换到另一个项目，展示项目间隔离。
- 返回原项目，勾选成果和问题，填写「核对最近两期财报中的收入、应收账款及经营现金流变化」，创建新会话。
- 展示新会话中的研究背景，说明用户可以接着验证问题，不必重新整理上一次的判断。此步骤会按当前模型配置发起真实研究请求。

汇报可以这样描述：本次完成了项目级研究成果与待办问题的保存和接续。研究成果可以追溯到原回答和资料，研究员可以明确区分已确认判断与待验证问题，并选择需要的背景开启下一轮研究。

## 数据与接口

- 核心持久化：PE 项目的现有研究 SQLite 数据库，新增 `research_cards` 和 `research_card_revisions` 表。卡片含项目、类型、标题、内容、状态、证据引用、关联卡片、关联框架条目、原回答身份及摘录、版本、时间和归档标记。框架关联使用稳定条目 ID，并在创建或新增关联时校验当前项目的最新已发布框架。
- `GET /api/pe/research-cards?datasetId=...` 读取当前项目卡片。
- `POST /api/pe/research-cards` 创建或更新卡片；请求标识用于重复保存去重，版本号用于检测并发修改。
- `/api/agent/new` 的可选 `researchContext` 接收项目及卡片版本选择，在创建会话前校验并生成上下文。
- 来源回答由服务端从项目会话中读取并验证，选中文字与经过清理的 Markdown 展示文本核对，支持跨加粗、链接、列表和表格的连续选择。客户端不能用任意文本冒充原回答，缺少摘录或核对失败时不会保存全文。修改卡片不会覆盖原始摘录，也不会改变已经发送到新会话的研究背景。
- 资料入口继承自原回答或关联卡片，仍需判断是否支持当前结论。人工确认表示研究员保留该判断，不代表系统已经验证其真实性或时效性。

## 第一版边界

研究背景由用户主动保存和选择。已有历史研究笔记不会自动导入。每次最多选 20 张卡片，上下文超过 60000 字符时提示缩小选择，不会静默截断。每次摘录限同一回答中的连续选区，最多 20000 字符；无法核对的图表或交互组件展示文字会提示重新选择，不会回退保存全文。
