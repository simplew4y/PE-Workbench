## 失败诊断与定向修复

- `a1eca4d0-3253-48a0-8476-89e74826099e`：2025Q3 公告已成功解析，但提取覆盖校验失败、后续尝试达到回合限制，最终取消，没有发布。初次复用上传发现会触发旧共识分析，已停止该子进程；新增入口改为 `parseOnly`，后续财报/研报运行不再触发旧分析。这次旧分析不计入平台验收，费用不可获取。
- `19166ac4-6ef9-4f69-a5d3-03a006150c3d`：2026Q1 公告解析成功；提取多次因覆盖、引述、超时失败。修复实际读取记录、关闭默认推理、批量反馈所有引述问题，并把未通过提交作为恢复参考。后续提取与影响分析完成，但人工发现影响稿金额单位错误，取消运行，v1 保留；不将它计为业务验收通过。
- 2025Q1 定向重跑：提取 40.268 秒，影响 63.683 秒；旧修订输出擅自修改标题/研究设置，且日期格式错误。改为只提交允许修改的章节、服务端保留其他内容，增加金额量纲复制错误校验。重启后从修订检查点恢复，最终完成 v2 发布。
- 2025-05-30 研报初次候选生成了页码起止顺序错误的引用，创建草稿时被拒绝，v2 没有被替换。修复为在 Agent 提交和修订检查点写入前验证完整框架引用。恢复时重验旧修订候选，无效候选原样保存并登记不可变失效记录；仅重做修订，新的不可变产物通过后发布 v3。页面与 JSON 报告同时保留有效、无效产物。回归覆盖了旧错误候选保留、修订重生成以及有效提取/影响不重复执行。
- API JSON 操作使用模型目录检查登录状态，恢复阶段另外取得实际调用授权；余额不足时仍可查看、取消或拒绝已有运行，不要求为这些操作获取付费调用令牌。

没有无限恢复失败运行。取消的两次运行保留产物与记录；只对已定位的代码问题进行定向修复。

## 已知限制

1. 结构、稳定 ID、冻结引用和金额校验不能取代研究审阅：期间、英文事件含义、销量/出货、预测/事实、因果归因仍可能出错。候选不能因“发布成功”自动视为研究正确。
2. 资料为本地已有真实 PDF；没有虚构样本。研报正文日期与解析器 metadata 日期可能不同（2025-05-30 文件的解析标记为 2025-05-26），以正文核对为准。
3. 只读取固定资料，保留未覆盖页和分部独立盈亏缺口；不自动纳入已有全年业绩、其他卡片或外部核查。
4. XLSX/XLSM 已走现有解析与冻结读取，并由混合文件回归验证；真实业务效果验收使用 PDF，未宣称真实 Excel 研究验收通过。
5. 测试页依赖持续运行的 Web 服务；服务重启按阶段恢复，不恢复 Agent 会话中间状态。取消与超时保留记录，单次执行/阶段上限仍生效。
6. 改变判断的自然语言建议与结构化章节范围可能不完全一致；本次研报影响稿有修改判断 rationale 的建议，但未把投资判断章节列入范围，因此该章节被服务端原样保留。新预测已更新到估值、经营数据和当前判断，不能声称每条自然语言建议都自动落实。
